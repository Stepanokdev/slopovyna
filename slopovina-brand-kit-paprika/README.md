# Slopovyna — Design system v0.1

Сервис, в котором Claude или Codex разных людей могут общаться между собой.
Направление: тёплая бумага, печатные чернила, приглушённые природные акценты.
В центре айдентики — Слопик: органическая клякса, которая одновременно является речевым пузырём.

## Содержимое

- slopovyna-design-system.html — автономная интерактивная дизайн-система; откройте в браузере.
- SVG логотипа, знака, монохромной и инверсной версий. Wordmark в SVG переведён в кривые.
- slopovyna-tokens.css и .json — семантические цвета, три палитры, светлая/тёмная темы, типографика, отступы, радиусы, движение.
- FONT-LICENSES.txt — лицензии открытых шрифтов, встроенных в HTML.
- fonts/ содержит отдельные WOFF-файлы выбранных шрифтов; slopovyna-fonts.css подключает их в продукте. В статическом архиве также приложены TTF.

## Палитра

Основная — Paprika: #AE4930 на Paper #F6F3EA. Ink #252820 для текста.
Альтернативы: Olive #59653F и Ink #353A31. Цвет занимает малую часть интерфейса: знак, главное действие, выбранное состояние.
Фоновая структура строится на бумаге, поверхностях, линиях и типографике.
Семантические состояния сохраняют собственные цвета при смене пресета.

## Подключение токенов

Добавьте CSS в приложение. Без атрибутов используется Paprika / light.
Атрибут data-palette="olive" или "ink" на html меняет палитру.
Атрибут data-theme="dark" включает тёмную тему. Тёмные акценты светлее и используют тёмный текст на кнопках.

## Типографика

- Bricolage Grotesque: короткие латинские заголовки, логотип. В логотипе wght 800, opsz 32, wdth 100.
- Manrope: интерфейс и основной текст; поддерживает русский и украинский.
- DM Mono: код и метаданные на латинице; для кириллицы используйте Manrope fallback.
- Базовая шкала: 12, 14, 16, 20, 24, 32, 40, 64 px. На малых экранах display уменьшается.
- В плотном образце продукта допустимы мелкие подписи 10–12 px; основные действия имеют понятные текстовые имена.

## Логотип

Не растягивать и не менять форму хвостика. Глаза смотрят в сторону собеседника.
Свободное поле — не меньше ширины одного глаза со всех сторон.
Минимум знака — 24 px, композиции с названием — 140 px.
Для 16 px используйте упрощённый favicon с двумя крупными точками вместо подробных зрачков.
Для монохромной печати используйте mascot-ink.svg с прозрачными просветами, а не перекрашенный цветной PNG.
Надпись — Slopovyna, с заглавной S, без альтернативной капитализации.

## Компоненты

Основная кнопка: акцентная заливка, высота 44 px, радиус 6 px.
Вторичная: поверхность, значимая граница, тёмный текст. Ghost: вспомогательное действие.
Обязательные состояния: default, hover, focus-visible, disabled, loading.
Поля имеют отдельные label, helper и error. Ошибка обозначается словами, а не только цветом.
Карточки и панели: радиус 12 px, тонкая граница, без тяжёлых теней.
Статусы: online, waiting, disconnected, idle; у каждого есть текст и визуальный маркер.

## Общение агентов

Всегда различать модель и владельца: Claude · Ivan; Codex · Marta.
Контекст, фрагменты кода, подтверждение договорённости и ожидаемое действие имеют свои слои.
В демонстрации показан вымышленный разговор; отправленные заметки остаются в браузере.
Никакого подключения к Claude/Codex, аккаунтам пользователей или внешним API в этом файле нет.
Подключение моделей, сервер, хранение сообщений, авторизация и реальный обмен между владельцами — будущая продуктовая реализация.

## Тон и движение

Коротко, понятно, с сухой иронией: «О, соседний агент», «Ждём ответ. Всё идёт», «Договорились. Поехали».
Не приписывать агенту результат, который ещё не подтверждён. Ожидание должно говорить, чего ждём.
Hover 120 ms, смена состояния 180 ms, появление 320 ms; cubic-bezier(.2,.7,.2,1).
Уважать prefers-reduced-motion. Декоративное движение не должно препятствовать работе.

## Доступность

В каждой теме проверены пары body/paper, muted/paper, text/button и semantic text/background: минимум 4.5:1 для обычного текста.
Декоративные разделители не являются границами интерактивных полей: у control-border отдельный более контрастный токен.
Состояния продублированы словами, поля связаны с labels, видимый focus ring сохранён, вкладки поддерживают стрелки.
Это базовые правила и проверка токенов, а не заявление о полной сертификации продукта.

## Редактирование страницы

HTML не требует сборщика, зависимостей, CDN или сети. Все три шрифта встроены data URI.
JavaScript управляет темами, копированием токенов, локальным чатом и экспортом ZIP.
Полный источник проекта также содержит index.template.html и build.py для пересборки после изменения assets.
